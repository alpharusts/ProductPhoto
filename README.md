# Фото товара — белый фон для маркетплейсов

Бесплатное Android-приложение от **MiniSul**: готовит фото товаров для Kaspi, Ozon, Wildberries и других площадок.

- **Убирает фон** — товар вырезается автоматически прямо на телефоне и ставится на белый фон.
- **Готовые форматы:** Kaspi (1:1, 1500×1500), Ozon и Wildberries (3:4, 1200×1600), квадрат 2000×2000.
- **Пачкой до 30 фото** за раз, товар по центру с одинаковыми полями.
- **Артикул в имени файла:** `A123_1.jpg`, `A123_2.jpg`…
- Сохраняет в Галерею (`Pictures/MiniSul/<площадка>`) и сразу отправляет в Telegram и другие приложения.
- Без рекламы, без регистрации, фото никуда не отправляются.

Android 8.0 и новее. Для вырезания фона нужны сервисы Google Play (модель скачивается один раз).
